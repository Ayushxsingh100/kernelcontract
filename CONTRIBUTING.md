# Contributing

Thanks for considering a contribution.

1. Open an issue with a reproducible environment or notebook failure.
2. Explain the expected result and the observed result, including Python/Jupyter versions where possible.
3. Avoid adding a compatibility rule unless it is backed by authoritative documentation or a reproducible test case.
4. Keep checks read-only; do not add automatic package installs or environment edits to the diagnostic path.
5. Run `python -m pytest` before submitting a pull request.

Please remove credentials, private paths, notebook outputs, and sensitive data before sharing logs or fixtures.
